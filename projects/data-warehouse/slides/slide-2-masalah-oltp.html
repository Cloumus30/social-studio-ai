Kenapa Database Aplikasi Nggak Kuat?

PostgreSQL atau MySQL didesain berbasis baris (row-store). Sangat efisien buat tulis-baca kasir per user, tapi kewalahan saat dipaksa agregasi jutaan baris laporan.

Glosarium Simpel

• OLTP (Online Transaction Processing): Sistem kasir toko. Cepat catat transaksi satu per satu (checkout, login).

• OLAP (Online Analytical Processing): Ruang arsip analitik. Khusus hitung jutaan data lampau tanpa ganggu kasir.

Bahaya Tanpa Pemisahan

• Table Locking: Transaksi kasir/checkout terhenti menunggu kalkulasi laporan selesai.

• CPU 100%: Server database operasional kehabisan tenaga hingga aplikasi crash.
